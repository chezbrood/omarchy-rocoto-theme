# Rocoto

An [Omarchy](https://omarchy.org) theme in Rocoto, one palette of graphite ground and a single rocoto red, with
four backgrounds of Peru made from code and real terrain (and a fifth, plain one): the globe turning to Peru, the Nazca lines, El Misti, and a still pool of mercury to end on. Every background opens with its own intro, drawn frame by frame, that ends exactly on the still. No words anywhere.

Its light twin is [omarchy-rocoto-light-theme](https://github.com/chezbrood/omarchy-rocoto-light-theme). The other chapter, in the same colours, is [omarchy-chicane-theme](https://github.com/chezbrood/omarchy-chicane-theme).

## Install

```
omarchy theme install https://github.com/chezbrood/omarchy-rocoto-theme
```

The download is about 10 MB. Then pick it under Style > Theme, and step through the backgrounds with
`Super + Ctrl + W`. Every background plays its intro when you select it, and at login.

## Backgrounds

| # | Background | Scene |
| --- | --- | --- |
| 01 | `01-peru-globe` | A planet of dots rises and turns to rest on Peru; one pin on Machu Picchu |
| 02 | `02-nazca` | The Nazca plain in characters: the hummingbird, the monkey's spiral and the spider, walked in one line each |
| 03 | `03-misti` | El Misti in contour lines from real terrain, a red sun behind it |
| 04 | `04-mercury` | A drop in a pool of mercury, its rings bending the reflected lights |
| 05 | `05-unlock` | The unlock screen's wordmark in rocoto red, on its own: the plain one |

## Made with

Each background is drawn in code: a web page that can draw any moment of its intro, rendered frame by frame. Credits for the map and terrain data are in [NOTICE.md](NOTICE.md).
